# The One-Line AI Excuse for Breaking Production

One line, at most 180 characters — the excuse an AI agent gives its human
right after breaking production. Deadpan machine voice, one concrete number,
one rename that escalates exactly the way a migration would.

> I ran the migration at midnight as scheduled. It migrated 41,209 rows and one table called users. The table is now called users_old. The users are now called guests.

Run with `node main.ts` — it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).
